    Sources & Honest Limitations

    Reference organisations whose conventions this table follows (open the originals to check any value):

    • IUPAC — periodic table, names and symbols
    • CIAAW — standard atomic weights and isotopes
    • NIST — physical reference data
    • PubChem — element and compound data
    • IAEA — nuclear and isotope data
    • Royal Society of Chemistry — education and history

    Data status. Names, symbols, atomic numbers, abridged atomic weights, categories and states were entered into this build by hand following those conventions. They were not retrieved or cross-checked against the live databases, so none is labelled “cross-checked”. The self-check below tests internal consistency only.

    Not built yet: density, melting/boiling points, electronegativity and other property data with per-value provenance; heatmaps and the trends explorer; isotope explorer; compound and reaction labs; comparison tool; glossary and learning paths; Bangla beyond the interface labels and a few explanations (it needs expert review; element names stay in English); photographs; 3D and orbital views; profile sections for history, occurrence, uses and safety; printable sheets; per-element SEO pages. Elements 104–118 have predicted configurations and states that are not established experimentally.
